# P0 汉化范围（Cursor 3.27.22，Windows 桌面版）

> 版本锁定：P0 清单与 **100% 覆盖率只针对 3.27.22**。Cursor 每个版本都会增删、改名界面字符串，升级到新版本后必须重新核对本清单和字符串覆盖率。
> 版本不是 3.27.22 时，安装脚本给出警告，仍继续打补丁，并报告已匹配与未匹配的字符串数量；未匹配的字符串保持英文。其他版本的验收只要求**不崩溃、能还原**（见 `docs/acceptance.md`）。
> 重要说明：产品侧**无法检查 3.27.22 的安装包/二进制**，下列元素是“预期用户最常看到、需要验证的区域”，**不是从安装包中提取的字符串清单**。实际字符串清单由开发人员一从 3.27.22 中提取后，按本文件的区域归类，作为覆盖率统计的分母（见 `docs/acceptance.md`）。

术语一律以 `docs/glossary.md` 为准。

## 优先级定义
- **P0**：用户每天使用 Cursor 都会看到的 Cursor 专有界面，首个版本必须 100% 覆盖。
- **P1**：使用频率较低或入口较深的 Cursor 界面，首个版本尽量覆盖，不阻断发布。
- **不在范围内**：由其他渠道已覆盖，或技术上无法在本地补丁中处理的内容。

## P0-1 聊天面板（Chat / Agent 输入区）
需验证的元素：
- [ ] 聊天输入框占位符（如 “Plan, search, build anything...” 类文案）
- [ ] 模式切换器：Agent / Ask / Plan / Manual（模式名保留英文，下拉说明文字翻译）
- [ ] 模型选择器：Auto、Max Mode 开关、“思考”等能力标签、“添加模型/更多模型”入口（模型名本身不译）
- [ ] 本地 / 云端（Local / Cloud）运行位置选择
- [ ] 发送、停止、排队、立即发送按钮及其 tooltip
- [ ] 上下文标签（context pills）：已添加的文件、文件夹、终端、文档等标签及“移除”操作
- [ ] `@` 提及菜单：仅当显示字符串与插入 token 在代码中是不同字符串时，才翻译显示文字（文件和文件夹、代码、文档、网页、终端、聊天、Git 等）。同一字符串兼作显示和插入的保持英文，由开发人员一在其 PR 中列出
- [ ] `/` 命令菜单的说明文字（命令本身如 `/create-rule` 不译）
- [ ] 上下文用量环及明细面板（系统提示词、工具、规则、技能、MCP、子 Agent、已摘要的对话、对话）
- [ ] 图片/文件附件按钮、语音输入按钮
- [ ] 新聊天、聊天历史、重命名、删除聊天
- [ ] 消息操作：复制、重试/重新生成、点赞/点踩、编辑消息

## P0-2 Agent 面板（执行与审查）
- [ ] 工具调用状态行：正在读取文件、正在搜索代码库、正在编辑、正在运行命令、网页搜索等
- [ ] 终端命令确认栏：运行 / 跳过 / 允许 / 拒绝、“始终允许”类选项
- [ ] MCP 工具批准提示（工具名不译，按钮与说明翻译）
- [ ] 应用 / 接受 / 拒绝 / 全部接受 / 全部拒绝 / 接受文件 / 拒绝文件 / 撤销 / 保留 按钮栏
- [ ] 审查与 Diff 视图：文件更改列表、增删行数、“审查更改”“查看差异”入口（标签/按钮用“差异”，技术名词保留 “Diff”）
- [ ] 检查点：时间线中的检查点、“还原检查点”按钮、还原确认对话框
- [ ] Plan 模式：计划文件头部、“构建”（Build）按钮、“保存到工作区”
- [ ] Agent 提问卡片（Ask questions）：选项、跳过、提交
- [ ] 排队消息列表、拖动排序提示
- [ ] Agent 运行中/已完成/已停止/出错等状态文字
- [ ] Agent 窗口（Agents Window）中的 Agent 列表、筛选、搜索框占位符

## P0-3 Cursor 设置页（Ctrl+Shift+J）
设置页左侧导航与各页标题、分区标题、开关标签、说明文字：
- [ ] 常规（General）：账户、登录/退出登录、隐私模式、编辑器设置入口、通知相关开关
- [ ] 模型（Models）：模型列表开关、“添加模型”、API 密钥区域（密钥字段名不译）
- [ ] Agent / 聊天相关设置：自动运行、命令允许/拒绝列表、自动应用、默认模式等
- [ ] Tab：Tab 补全开关、部分接受、自动导入等
- [ ] 规则（Rules）：用户规则、项目规则、“添加规则”、规则类型下拉（始终应用 / 智能应用 / 应用于特定文件 / 手动应用）
- [ ] MCP：MCP 服务器列表、状态（已连接/出错/已禁用）、“添加 MCP 服务器”、刷新、工具数量
- [ ] 索引（Indexing）：代码库索引进度、重新索引、删除索引、忽略文件设置
- [ ] 文档（Docs）：添加文档源
- [ ] 自定义 / 插件 / 技能（若 3.27.22 设置页中存在）
- [ ] Beta：各实验性功能开关的标题和说明
- [ ] 用量与方案入口文案（本地静态部分；服务端返回的数值与方案说明除外）

## P0-4 命令面板中的 Cursor 命令
- [ ] 所有以 `Cursor:` 为分类前缀的命令（前缀保留 `Cursor:`，命令名翻译），例如打开 Cursor 设置、新建 Cursor 规则、尝试更新、重新索引等
- [ ] Cursor 新增的、非 `Cursor:` 前缀但属于 Cursor 功能的命令（如 Agent、Composer、聊天相关命令）
- [ ] VS Code 原生命令仍可用英文搜索（由官方 zh-hans 语言包保证）。Cursor 自有命令的英文搜索为**待验证**，不阻断发布（开发人员一在真实安装包上确认）

## P0-5 通知（Toast / 对话框 / 错误）
- [ ] Cursor 本地生成的 Toast：更新可用、更新已下载、需要重启、索引完成、MCP 服务器连接失败、规则加载失败等
- [ ] 登录/会话过期提示、网络错误提示（如 HTTP 兼容模式相关提示）
- [ ] 用量/限额提示中**本地内置**的文案框架（如“你已达到用量上限”+“升级方案”按钮）
- [ ] 确认对话框：还原检查点、删除聊天、拒绝全部更改、丢弃更改
- [ ] 状态栏 Cursor 项：Tab 状态指示器、索引状态、Cursor 账户状态

## P1（首个版本尽量覆盖，不阻断发布）
- 内联编辑（Ctrl+K）浮层与提示
- Bugbot 在 IDE 中的入口文案
- Cloud Agent 详情页、环境配置界面
- 新手引导（Onboarding）、欢迎页中 Cursor 专有部分
- 键盘快捷方式编辑器中 Cursor 命令的说明文字
- Cursor 专有的右键菜单项、编辑器标题栏按钮
- 不常用设置页（网络、高级、实验性子页）

## 不在范围内
- **VS Code 核心界面**（菜单栏、资源管理器、搜索、源代码管理、调试、扩展、终端面板、设置编辑器中的 VS Code 设置）：由 VS Code 官方简体中文语言包（nls，locale=zh-cn）覆盖。Cursor 自有界面由补丁替换 `workbench.*.main.js` 中的字符串，并重算 `product.json` 校验和。本项目只需确保补丁与语言包共存时不冲突、术语不打架。
- 第三方扩展界面。
- **服务端下发的内容**（**已定**，补丁无法触及，排除在范围外）：模型列表与说明、方案/价格说明、用量数值、部分错误信息、公告、更新日志。
- 模型（AI）回复内容。
- Cursor 官网、营销页面、cursor.com 仪表盘、官方文档。
- macOS、Linux 版本。3.27.22 以外的 Windows 版本不按本清单要求 P0 100% 覆盖；脚本仍会打补丁，未匹配的字符串保持英文，验收只要求不崩溃、能还原。
- CLI（`cursor-agent` 等命令行工具）输出。
