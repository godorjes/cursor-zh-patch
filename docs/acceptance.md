# 发布验收标准（Cursor 3.27.22 简体中文补丁）

> 适用对象：测试人员一（执行），开发人员一（修复），产品（判定是否可发布）
> 版本锁定：Windows 桌面版 Cursor **3.27.22**。P0 100% 覆盖率只适用于 3.27.22；其他版本的发布门槛只有**不崩溃、能还原**。
> 依据：`docs/glossary.md`（术语）、`docs/p0-scope.md`（范围）

## 1. 发布门槛（全部满足才可发布）

| # | 标准 | 通过条件 |
| --- | --- | --- |
| G1 | P0 覆盖率 | **只适用于 3.27.22**：P0 区域可见字符串 **100%** 已翻译（分母为开发人员一从 3.27.22 提取并归类到 P0 的字符串清单；服务端下发内容不计入）。其他版本不适用本条 |
| G2 | P1 覆盖率 | 目标 ≥ 80%，**不阻断**发布；实际值写入发布说明 |
| G3 | 占位符与快捷键 | 损坏的占位符、快捷键、代码标记数 = **0**（自动检查 + 人工抽查） |
| G4 | 稳定性 | 打补丁后无崩溃、无白屏/空白面板、无控制台报错导致的功能失效 |
| G5 | 术语一致性 | P0 范围内与术语表不一致的地方 = **0** |
| G6 | 截断/溢出 | 默认窗口大小以及 Windows 缩放 125%、150% 下，P0 元素无截断、无重叠、无文字溢出容器（可用省略号截断的 tooltip 除外） |
| G7 | 还原 | 卸载/还原后界面恢复为英文，功能正常，无残留中文 |
| G8 | 重启持久 | 重启 Cursor 后汉化仍然生效；重启电脑后仍然生效 |
| G9 | 完整性警告 | 已记录打补丁后 Cursor 是否显示“安装已损坏/不受支持”类警告，以及处理方式，并写入 README |
| G10 | 本机验证 | **必做**：先在用户自己的机器上备份，再在真实机器上验证一次。测试人员一当前在复制的安装目录和模拟环境中执行。干净安装（全新安装的 3.27.22，无旧配置、无其他汉化补丁）为**建议**，不阻断发布 |
| G11 | 缺陷 | 无未关闭的“阻断”和“严重”级缺陷 |

> 版本不是 3.27.22 时，安装脚本给出警告，仍继续打补丁，并报告已匹配与未匹配的字符串数量；未匹配的字符串保持英文。P0 100% 覆盖率（G1）**只适用于 3.27.22**。其他版本的发布门槛只有**不崩溃、能还原**。
> 干净安装，以及 Windows 10 与 Windows 11 各一台（虚拟机可），均为**建议**，不阻断发布。

## 2. 测试环境
- **必做**：先在用户自己的机器上备份，再在真实机器上验证一次
- 测试人员一当前在复制的安装目录和模拟环境中执行
- **建议**（不阻断发布）：Windows 10 22H2 与 Windows 11 23H2 及以上，各至少一台（虚拟机可）
- **建议**（不阻断发布）：Cursor 3.27.22 官方安装包干净安装（安装前删除 `%APPDATA%\Cursor` 和 `%USERPROFILE%\.cursor`，测试完毕再恢复）
- 两种组合：① 仅本补丁；② 本补丁 + VS Code 官方简体中文语言包，并将显示语言设为 `zh-cn`
- 分辨率 1920×1080；缩放 100% / 125% / 150%
- 记录：Cursor 版本号（帮助 > 关于）、补丁版本号与提交 SHA、操作系统版本

- [ ] 安装前自动备份原始文件，备份位置已记录
- [ ] 版本不是 3.27.22 时，脚本给出警告，仍继续打补丁；未匹配的字符串保持英文
- [ ] 记录匹配报告：已匹配 ___ 条，未匹配 ___ 条
- [ ] 非 3.27.22 只按“不崩溃、能还原”验收；P0 100% 覆盖率仅适用于 3.27.22
- [ ] 先在用户自己的机器上备份，再在真实机器上验证一次
- [ ] 已注明本次测试在复制的安装目录和模拟环境中进行

## 4. 缺陷严重程度

| 级别 | 定义 | 示例 | 是否阻断发布 |
| --- | --- | --- | --- |
| 阻断 | 导致崩溃、无法启动、白屏、核心功能不可用、数据/代码丢失，或无法还原 | 打补丁后 Agent 面板空白；接受按钮失效；占位符损坏导致报错；卸载后无法恢复英文 | **是**，必须修复 |
| 严重 | 功能可用但误导用户或明显不可用；P0 区域有未翻译、错译、截断导致看不懂 | “拒绝”误译为“接受”；P0 按钮被截断无法辨认；`{0}` 原样显示；快捷键显示错误 | **是**，必须修复 |
| 一般 | 不影响理解的翻译或显示问题 | 术语与术语表轻微不一致（P1 区域）；空格/标点不符合规范；P1 未翻译 | 否，记录在发布说明的已知问题中 |
| 建议 | 措辞可以更自然、更简洁 | 译文偏长但不截断；语序生硬 | 否 |

> 注：P0 区域内的术语偏差按“严重”处理（G5 要求 0 偏差）；P1 区域内按“一般”处理。
